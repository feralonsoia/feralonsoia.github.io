# Fernando Morquecho — Applied AI Portfolio

Personal portfolio showcasing applied AI, conversational agents, LLM workflows,
technical education, and machine learning projects.

## Featured project

**NovaMart / Eco** is a live ElevenLabs voice-agent project that handles customer
support workflows, protects sensitive actions with identity verification, and
controls the storefront through voice commands.

- Live demo: <https://novamart-eco.pages.dev>
- Portfolio: <https://feralonsoia.github.io>

## Run locally

No build step is required. Open `index.html` directly or start a local server:

```bash
python3 -m http.server 8080
```

Then visit <http://localhost:8080>.
